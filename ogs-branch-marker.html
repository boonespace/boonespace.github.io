OGS Branch Marker

在 OGS Review 页面，标记当前局面下各分支的下一步位置。实心圆点，颜色可调。

安装

把下面的按钮拖拽到浏览器书签栏：

ogs-branch-mark

点击书签开启，再点击一次关闭。右侧边栏顶部会出现控制面板，可调颜色和透明度。

拖拽不生效？
某些浏览器会拦截从本地 HTML 拖拽的 javascript: 链接。
如果拖不动，请手动创建书签：右键书签栏 → 添加书签，名称填 ogs-branch-mark，网址粘贴下方代码。

使用

  1. 在 OGS Review 页面，点击书签栏上的 ogs-branch-mark
  2. 右侧边栏顶部出现控制面板，可调 R/G/B/A
  3. 切换节点时，当前局面的下一步会自动标记
  4. 再次点击书签，或点面板上的 x，关闭并清除标记
